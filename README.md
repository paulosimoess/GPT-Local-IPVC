# GPT Local para recomendação e consulta de cursos do IPVC

Projeto académico desenvolvido em pares com recurso a tecnologias e plataformas open-source.

## Tema
Desenvolvimento de um GPT Local para recomendação e consulta de cursos do IPVC.

## Objetivo
Criar um sistema baseado em GPT Local capaz de responder a perguntas sobre cursos do IPVC, recomendar opções de acordo com os interesses do utilizador e consultar informação académica com base em dados estruturados e não estruturados.

## Fontes de informação
- Dados estruturados: cursos, duração, ECTS, médias, regime, vagas, entre outros
- Dados não estruturados: regulamentos, brochuras, guias do estudante, planos curriculares e outros documentos em PDF

## Estrutura do projeto
- `data/estruturados/` → ficheiros CSV/JSON com dados organizados
- `data/nao_estruturados/` → documentos PDF e outros ficheiros textuais
- `docs/` → documentação de apoio ao projeto
- `src/` → código-fonte
- `tests/` → testes
